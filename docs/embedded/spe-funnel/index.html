What is SharePoint Embedded?

SharePoint Embedded delivers Microsoft 365 superpowers as part of any app. It's a headless, API-only solution built on the Graph API, which makes it easy and fast for developers to deliver a globally compliant, full-featured file and document management roadmap — that delights both admins and users.

Suitable for building line-of-business and ISV applications, SPE is the same robust platform that powers Microsoft Loop and Microsoft Designer.

📦
File Storage Containers
SharePoint Embedded creates dedicated File Storage Containers within a Microsoft 365 tenant — isolated, permissioned, and fully controlled by your application.
🗂️
App-managed Content Experiences
Utilize rich content features including support for various file types, folder structures, search, sharing, versioning, and real-time collaboration — all via Graph API.
🛡️
Secure and Isolated
Each container is accessible only by the app that created it. A dedicated partition in your Microsoft tenant ensures your files and documents remain secure.
✨
More with Microsoft 365 Copilot
Microsoft 365 Copilot subscribers have access to SharePoint Embedded data, enabling AI-powered summarization, search, and document intelligence over your content.
🌍
Cloud-based Document Management
Suitable for any application that needs to handle documents, files, and content — with Microsoft 365's globally compliant file storage capabilities built in.

Key Benefits

Enhancing integration between custom applications and the robust document management capabilities of Microsoft 365.

Seamless Microsoft 365 Integration Full integration with the Microsoft 365 ecosystem — compliance, security, identity, and storage — inherited automatically by every app you build.
Real-time Co-authoring with Office Deliver real-time co-authoring with Office and rich security and compliance by integrating with Microsoft Purview — without any custom infrastructure.
Same Platform as Microsoft Loop & Designer Experience the same robust platform that powers Microsoft Loop and Microsoft Designer — production-grade reliability with Microsoft's investment behind it.
Dedicated, Secure Isolation Secure isolation of your application with dedicated partitions in your tenant — your content is never commingled with other apps or SharePoint sites.
