Setup Guide

Adobe Analytics Real-Time Setup

Step-by-step guide to connect the SPE Funnel to Adobe Customer Journey Analytics (CJA) using the Adobe Experience Platform Web SDK.

Browser (SPE Funnel) │ │ alloy("sendEvent", { xdm: { ... } }) ▼ Adobe Experience Platform Edge Network │ (Datastream routes the event) ├──▶ AEP Dataset (raw XDM events stored) │ ▼ Adobe Customer Journey Analytics (CJA) │ Connection → Data View → Workspace ├──▶ Fallout / Funnel Panel (persona drop-off) ├──▶ Flow Panel (journey paths) └──▶ Freeform Table (doc engagement)
Steps in this guide
  • 1Create an XDM Schema in Adobe Experience Platform
  • 2Create an AEP Dataset
  • 3Configure a Datastream
  • 4Install and configure the Web SDK (alloy.js)
  • 5Update analytics.js with your IDs

⚠️
Prerequisites: You need an active Adobe Experience Cloud organization with licenses for Adobe Experience Platform and Customer Journey Analytics. Contact your Adobe account team if you are unsure of your entitlements.
1

Create an XDM Schema in Adobe Experience Platform

Define the data shape that all SPE funnel events will follow.

A Navigate to Schemas

Log in to experience.adobe.com, select your organization, then go to Data Management → Schemas.

B Create a new schema
  • Click Create schema → XDM ExperienceEvent
  • Name it: SPE Funnel Events
C Add standard field groups

Click Add field group and add all of the following:

  • AEP Web SDK ExperienceEvent — captures page URL, referrer, user agent
  • Web Details — web page name, link interactions
  • Environment Details — browser, OS, screen resolution
D Add a custom field group for SPE dimensions

Click Add field group → Create new field group. Name it SharePoint Embedded Funnel. Then add these fields under the tenant namespace (e.g. _microsoft):

Field pathTypeDescription
_microsoft.sharePointEmbedded.personastringdeveloper | admin | decision-maker
_microsoft.sharePointEmbedded.journeyStepintegerStep number (1-indexed)
_microsoft.sharePointEmbedded.stepIdstringUnique step ID e.g. dev-7
_microsoft.sharePointEmbedded.stepTitlestringHuman-readable step name
_microsoft.sharePointEmbedded.phaseNamestringPhase name e.g. Core Development
_microsoft.sharePointEmbedded.documentUrlstringMicrosoft Learn URL opened
_microsoft.sharePointEmbedded.completedbooleanWhether step was marked complete
_microsoft.sharePointEmbedded.sessionIdstringBrowser session identifier
_microsoft.sharePointEmbedded.funnelVersionstringSchema version string
ℹ️
The tenant namespace (_microsoft) is your Adobe org's unique identifier. It appears as a prefix in all custom fields. Find yours under Settings → Company info in the AEP UI.
E Enable the schema for Profile and enable primary identity
  • Toggle Profile on in the right panel
  • Set identityMap as the primary identity field
  • Click Save
✅
Copy the Schema ID from the right panel — you'll need it when creating the Dataset.
2

Create an AEP Dataset

A dataset is the storage container for all incoming events.

A Navigate to Datasets

Go to Data Management → Datasets → Create dataset.

B Create from schema
  • Select Create dataset from schema
  • Search for and select SPE Funnel Events
  • Name the dataset: SPE Funnel Events Dataset
  • Click Finish
C Enable for Profile

On the dataset detail page, toggle Profile on. This enables real-time identity stitching across sessions.

✅
Copy the Dataset ID — you'll reference it in the Datastream configuration.
3

Configure a Datastream

A Datastream is the server-side routing rule that tells the Edge Network where to send events.

A Navigate to Datastreams

Go to Data Collection → Datastreams → New Datastream.

B Configure the Datastream
  • Name: SPE Funnel - Production
  • Event Schema: select SPE Funnel Events
  • Click Save
C Add the Adobe Experience Platform service
  • Click Add Service → Adobe Experience Platform
  • Event Dataset: select SPE Funnel Events Dataset
  • Enable Edge Segmentation if available
  • Click Save
✅
Copy the Datastream ID (format: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx). This goes into analytics.js.
4

Install and Configure the Web SDK (alloy.js)

Load the Adobe Experience Platform Web SDK on every page of the SPE Funnel.

A Add the alloy.js script tag

In index.html, journey.html, and dashboard.html, replace the commented-out script tag with the live CDN version. Place it in the <head> before any other scripts:

<!-- Adobe Experience Platform Web SDK -->
<script>
  // Async loader snippet — place in <head> of every page
  !function(n,o){o.forEach(function(o){n[o]||((n.__alloyNS=n.__alloyNS||
  []).push(o),n[o]=function(){var u=arguments;
  return new Promise(function(i,l){n[o].q.push([i,l,u])})},
  n[o].q=[])})}(window,["alloy"]);
</script>
<script async
  src="https://cdn1.adoberesources.net/alloy/2.19.2/alloy.min.js"></script>
B Alternative: Adobe Tags (Launch)

If your organization uses Adobe Experience Platform Tags (formerly Launch), publish a Tags property that includes the AEP Web SDK extension. Then replace the snippet above with your Tags embed code. This approach is recommended for production as it allows no-code configuration changes without redeploying the HTML.

ℹ️
If using Tags, skip the manual alloy("configure") call in Step 5 — the Tags extension handles configuration. You only need to fire alloy("sendEvent", ...) from analytics.js.
5

Update analytics.js with Your IDs

Replace the placeholder values in the existing analytics file with your real Adobe credentials.

A Open analytics.js and update the constants
// At the top of analytics.js — replace these two values:

const DATASTREAM_ID = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx";
// Found in: AEP UI → Data Collection → Datastreams → [your stream] → copy ID

const IMS_ORG_ID    = "XXXXXXXXXXXXXXXXXXXXXXXX@AdobeOrg";
// Found in: AEP UI → Settings → Company info → Organization ID
B Update the initAlloy() call to remove the demo guard
initAlloy() {
  window.alloy("configure", {
    datastreamId:         DATASTREAM_ID,
    orgId:                IMS_ORG_ID,
    debugEnabled:         false,  // set true during testing
    clickCollectionEnabled: false  // we track clicks manually
  });
}
C Verify the XDM tenant namespace

In analytics.js, the custom fields are nested under _microsoft. Replace this key with your actual AEP tenant identifier if it differs:

// In the sendEvent() function inside analytics.js:
xdm: {
  eventType: eventType,
  _microsoft: {           ← replace with your tenant namespace
    sharePointEmbedded: {
      persona:     data.persona,
      journeyStep: data.stepIndex + 1,
      // ... rest of fields
    }
  }
}
ℹ️
Your tenant namespace is the prefix shown in AEP when you created the custom field group — e.g. _mycompany. It must exactly match what's in the schema.

6

Create a CJA Connection and Data View

Connect CJA to the AEP dataset and define which fields become metrics and dimensions.

A Create a Connection
  • In CJA, go to Connections → Create new connection
  • Name: SPE Funnel Connection
  • Sandbox: select the AEP sandbox where your dataset lives
  • Click Add datasets and select SPE Funnel Events Dataset
  • Set the Person ID to identityMap.ECID[0].id
  • Set Timestamp to timestamp
  • Click Save and continue
B Create a Data View
  • Go to Data Views → Create new data view
  • Select the connection you just created
  • Name: SPE Funnel Data View
C Add components (Dimensions and Metrics)

In the Components tab, drag the following schema fields from the left panel into the Dimensions or Metrics columns:

7

Build the Funnel Workspace in CJA

Create the three key analyses: persona funnel, step drop-off, and document engagement.

A Create a new Workspace project
  • Go to Workspace → Create project → Blank project
  • Select data view: SPE Funnel Data View
  • Name: SPE Onboarding Funnel
B Panel 1 — Persona Funnel (Fallout)
  • Insert a Fallout visualization
  • Add touchpoints using Event Type dimension filtered to each event in order:
Fallout touchpoints (in order):
  1. eventType = "spe.page_view"
  2. eventType = "spe.persona_selected"
  3. eventType = "spe.journey_started"
  4. eventType = "spe.step_viewed"    AND journeyStep = 3
  5. eventType = "spe.step_viewed"    AND journeyStep = 7
  6. eventType = "spe.step_completed" AND journeyStep = 7
  7. eventType = "spe.journey_completed"

Apply segment: Persona = "developer" | "admin" | "decision-maker"
to compare persona funnels side-by-side.
C Panel 2 — Step-by-step Drop-off (Freeform Table)
  • Insert a Freeform table
  • Rows: Step Title dimension
  • Columns: Events (count of spe.step_viewed), Events (count of spe.step_completed), calculated metric Completion Rate = step_completed ÷ step_viewed
  • Sort by Journey Step (ascending)
  • Apply conditional formatting on Completion Rate — red below 30%, green above 70%
D Panel 3 — Document Engagement
  • Insert a Freeform table
  • Rows: Document URL dimension
  • Columns: count of spe.doc_opened events, count of spe.step_completed events after doc open (create a sequential segment), Persona breakdown
E Panel 4 — Daily Traffic (Line chart)
  • Insert a Line visualization
  • Metric: Events, broken down by Persona
  • Date range: Rolling last 30 days
  • Granularity: Day
F Share the Workspace
  • Click Share → Share with Workspace users to grant access to your team
  • To embed in the dashboard page, use Share → Get project link and paste the URL into the iframe placeholder in dashboard.html
8

Validate with Adobe Experience Platform Debugger

Confirm events are firing correctly before publishing to production.

A Install the browser extension

Install the Adobe Experience Platform Debugger extension for Chrome or Firefox from the browser's extension store.

B Enable debug mode in alloy

Temporarily set debugEnabled: true in the initAlloy() call in analytics.js. This outputs verbose logs to the browser console and to the Debugger extension.

C Walk through the funnel and verify

Open index.html with the Debugger extension open. Check each of the following:

  • Opening the page fires spe.page_view with correct page URL
  • Clicking a persona card fires spe.persona_selected with the right persona value
  • Navigating to a step fires spe.step_viewed with correct journeyStep and stepId
  • Clicking "Open in Microsoft Learn" fires spe.doc_opened with the correct documentUrl
  • Clicking "Mark as Complete" fires spe.step_completed with completed: true
  • All events show datastreamId matching your Datastream
  • Edge Network returns HTTP 200 for all event requests
D Verify data in AEP Dataset

In AEP, go to Datasets → SPE Funnel Events Dataset → Preview. Allow up to 15 minutes for streaming data to appear. Confirm the custom fields under _microsoft.sharePointEmbedded are populated correctly.

⚠️
Remember to set debugEnabled: false before deploying to production. Also remove or gate the console.log fallback in analytics.js for production builds.
